# Vicky Garments - Saddar, Rawalpindi

High-fashion editorial advertising and direct WhatsApp ordering website for Vicky Garments located in Saddar, Rawalpindi, Pakistan.

## 🛍️ Live Website
[https://qasimkhanfaridi.github.io/vicky-garments/](https://qasimkhanfaridi.github.io/vicky-garments/)

## 🌟 Key Features
- **Rs. 500 & Rs. 700 Garment Collections**: Visually dominant deal promotions and product grid.
- **Direct WhatsApp Funnel**: Instant pre-filled ordering with product ID, price, title, and selected size (`S`, `M`, `L`, `XL`).
- **Store Location & Google Rating**: Real Saddar Rawalpindi location data with Google Maps directions button & verified 4.1 rating display.
- **TikTok Channel Integration**: Direct link to [@vicky.garment](https://www.tiktok.com/@vicky.garment).
- **Responsive Hybrid Design**: High-contrast luxury dark/light theme built with Next.js 14, Tailwind CSS, TypeScript, and Framer Motion.

## 🚀 Local Development

```bash
npm run dev
```
